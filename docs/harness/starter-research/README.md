# Starter Research Example

The [team spec](team-spec.html) shows how a collector can hand evidence to a
research lead in a later session. The [role brief](roles/research-lead.html) is
useful when the lead needs a separately selectable profile.

The collector writes `_workspace/01_source_findings.md`. The lead uses it to
produce `_workspace/final/report.md`. When a single session is enough, the
findings can stay in context. Add a source-research skill if the repository
has reusable research or citation procedures.
