# Antigravity Agent Adapter

| Capability | Mapping in the selected Antigravity environment |
| --- | --- |
| Skills | `supported` when Agent Skills discovery is enabled. Preserve `.agents/skills/` and use the deployment's documented discovery or import settings. |
| Roles | Verify custom-agent execution in the installed version and account. Reference portable roles from optional client profiles. |
| Write isolation | Shared-workspace ownership is `advisory`. Verify isolation before overlapping edits or stateful tests. |
| Communication | Verify whether result channels and background state are retained. Use a parent summary or durable workspace artifact when needed. |
| Model | Inherit settings unless the role needs a model control available in that environment. |

If workers or required isolation are unavailable, use direct or serialized work as the fallback where it can meet acceptance. Report any missing branch or unsupported guarantee. Keep client settings removable.
