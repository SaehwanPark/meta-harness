# Writing a Good `AGENTS.md`

Keep this automatically loaded file short, human-written, and limited to durable repo-wide guidance. Maintain the project's existing structure when it works.

| Section | Include when relevant |
| --- | --- |
| What | Project purpose, canonical paths, and boundaries an agent could confuse |
| Why | The reason for a non-obvious repository constraint |
| How | Exact build or verification commands and pointers to conditional guidance |

Put task-specific instructions in a skill or local document and link to them. Omit generated directory tours, rules already enforced by tools, and general advice the model already knows. Keep model-specific recovery in a removable adapter.
